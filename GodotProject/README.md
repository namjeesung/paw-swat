# 爪爪特警 PAW S.W.A.T. v0.9（Godot 4 原型 · 序章）

本包的运行说明、护盾规则、验证边界与经验总结见 `../README-中文.md` 和 `../Docs/TEST-REPORT.md`。本次只交付Web构建和可编辑工程，不含APK，也没有新部署服务器。

2.5D 45° 等距俯视的双摇杆射击游戏。猫狗特警 vs 浣熊匪帮。
剧本与设计见 [`../Docs/Original/SCRIPT.md`](../Docs/Original/SCRIPT.md)。

## 运行

1. 安装 **Godot 4.6.3**（本次实测/导出版本；原工程保持4.5声明）（标准版即可，不需要 .NET）：https://godotengine.org/download
2. 打开 Godot → 「导入」→ 选择本目录下的 `project.godot`
3. 按 F5 运行

首次打开会自动导入字体，稍等几秒。

## 手机 / 平板（主要平台）

- 本包Web沿用触屏布局；Android预设保留供后续开发，但本次未导出或真机验证APK
- 自己打包：Godot → 项目 → 导出 → Android（需在编辑器设置里配置 Android SDK 与 keystore）
- 电脑上预览触屏布局：`godot --path . -- --touch`

| 触屏 | 动作 |
|---|---|
| 左侧按住拖动 | 移动（浮动摇杆），角色面朝移动方向 |
| 右下任意位置按住 | 浮动开火摇杆：**锁定**目标自动连射（锁定后不乱跳，敌人脚下有锁定框） |
| 开火摇杆拖动 | 手动精准瞄准（已修正 45° 透视，指哪打哪，带轻微吸附） |
| 点屏幕上的敌人 | 切换锁定目标 |
| 暂停菜单「松手射击」 | 荒野乱斗式：拖动显示瞄准线，松手打出一轮 |
| 翻滚 / 冲撞 / 换弹 | 换弹圈走到黄色区域时再点一次 = 完美换弹 |
| 互动键（有目标时出现） | 破门 / 上铐 / 解救 |
| 武器键（有神装时出现） | 在步枪和捡到的各把神装之间来回切换 |
| 手雷键（有手雷时出现） | 扔向锁定目标（没锁定就扔最近的敌人），范围爆炸 |
| 右上 ⏸ / 安卓返回键 | 暂停 |

受击、破门会有震动反馈（暂停菜单可关闭）。

## 序章流程

进入便利店 → 清除店面和仓库的 8 名匪徒 → 破门（触发子弹时间）→ 制服劫持者 → 解救人质
→ 小米自己跑去门口的警车，警车鸣笛开走（安全撤离）
→ **僵尸鼠来袭**：拾取空投神器（像素风变身特写 + FIRE!）→ 坚守 60 秒（鼠王数量随难度 1 / 1 / 2 / 3 只）→ 空投炸弹清场 → 《毛绒日报》结算。

- 地面上的**橙色箭头**沿路线指向当前目标；目标变化时镜头会自动推过去特写
- 神装武器：喵喵散弹 / 罐头激光 / 肉垫火箭（敌人掉落），神器 · 罐头加特林（空投）。神装不伤人质。
  捡到的神装都会留在武器库里，可以随时切换；同种神装再捡一次会叠加弹药，打空才消失
- 临时护盾：僵尸潮中每22秒出现一次机会，5秒未暂停实际时间无敌，最多一件地面护盾，不叠加、不刷新，地面12秒消失。
- 罐头手雷：第一个被击倒的匪徒必掉，之后 30% 几率；僵尸潮里每 14 秒空投一箱。最多带 3 颗

- 匪徒被打空血量会**晕倒冒星星**，14 秒后会醒来，按 E 上铐才算彻底制服
- 浣熊开枪前会亮起**红色激光**预警，翻滚可以躲开
- 躲在柜台、箱子后面会自动蹲下，远处飞来的子弹会被挡住
- 人质被误伤次数达到上限（随难度 5 / 3 / 2 / 1 次），任务失败

所有角色、场景、图标都是用代码拼出来的几何体和矢量绘制，**没有外部美术素材**，之后可以逐个替换为正式模型。

## 难度

任务简报页右侧选择（电脑上也可按 1-4），会记住上次的选择。四档差距很大，各自单独排行：

| 难度 | 匪徒 | 匪徒血量 | 你的血量 / 受伤 | 僵尸潮 | 人质 |
|---|---|---|---|---|---|
| 初级 · 萌新 | 9 名 | ×0.5 | 200 血 / ×0.4 | 最多 8 只 | 能挨 5 下 |
| 中级 · 特警 | 11 名 | ×1 | 100 血 / ×1 | 最多 16 只 + 1 只鼠王 | 挨 3 下失败 |
| 高级 · 王牌 | 16 名 | ×1.7，4 连发 | 130 血 / ×1.25 | 最多 26 只 + 2 只鼠王 | 挨 2 下失败 |
| 鬼畜 · 地狱 | 23 名 | ×3，5 连发 | 90 血 / ×1.8 | 最多 34 只 + 3 只鼠王 | 误伤 1 下失败 |

所有数值集中在 `scripts/autoload/game.gd` 的 `DIFFS` 表里；追加匪徒的站位在 `level.gd` 的 `EXTRA_HARD / EXTRA_INSANE`。

## 医疗补给限额

初级/中级/高级/鬼畜每局最多成功生成1/2/3/4件医疗补给，定时空投和鼠王等奖励共用限额，按生成计数，地上最多一件。满血不会消耗，单件最多35HP并封顶；弹字显示实际恢复。暂停保留计数，重开捕获所选难度并重置。护盾、武器与手雷独立。

可选网页音频/版本诊断：按F8或实际HTML地址添加`?debug=audio`。默认隐藏，状态检查不等于真实听音通过。

## 自动测试

```bash
godot --headless --path . -- --autotest              # 跑完整流程，通关退出码 0
godot --headless --path . -- --autotest --diff=insane # 指定难度（easy / normal / hard / insane）
godot --path . -- --autotest --shots=/tmp/shots      # 同时保存各界面截图
godot --path . --resolution 2400x1080 -- --autotest --touch --touchtest   # 注入触屏事件，测试摇杆/按键
godot --path . -- --touch --touchdebug              # 触摸调试叠层（网页版：地址后加 ?debug=touch）
godot --headless --path . -s res://scripts/tools/bake_audio.gd                     # 修改音效合成代码后重新烘焙 WAV
```
