# 爪爪特警 v0.11 可编辑源码

GodotProject/project.godot 是项目入口；保留原4.5工程声明，用官方Godot4.6.3和匹配模板构建。源码、网页、APK分别交付，不能把本源码ZIP上传Toy。

## 改动

- 性能：静态同父节点角色细节合批，保留三角形、颜色、轮廓和动画；普通僵尸可见几何通道42→24，鼠王54→26。特效复用并限制数量，复用子弹查询，移除特效无必要的投影。物理步长统一60Hz
- 3D画面设1280×720等效像素预算，按实际窗口像素计算；HUD/文字和输入坐标不降分辨率。关闭4×MSAA；只在支持的Mobile/Forward+启用FXAA，Web/Compatibility不启用不支持的FXAA。未更换渲染器
- 道具：手雷所有来源共用每局最多两箱，地面一箱；首箱教学保留，此后敌人概率12%，空投间隔24秒。手雷地面20秒、普通武器30秒；普通武器每局最多三箱、地面一箱，非关键道具同时最多四件。剧情神器不受上限影响、不超时，保证流程可推进
- 回血仍是难度1/2/3/4生成上限，地面一件、满血留地上；护盾仍5秒不可叠加，地面12秒。生命、伤害、武器攻击规则未修改
- 鼠王：先重新寻路；持续约2.5游戏秒缺少净位移（包括来回抖动）后，标记落点预警1秒，重新验证后瞬移到玩家身边2–3米的可达、无碰撞位置。8秒冷却，落地0.6秒恢复后才攻击；仍可受伤。蓄力、眩晕、暂停、死亡/终局不触发，玩家移动或位置不安全就取消重试
- 触控：接受合法有符号手指ID，包括-1；修正重复/丢失结束、取消、隐藏/暂停/失焦/旋转后的输入状态。新增仅观察画布的被动事件记录，不重放输入、不全局拦截touchmove，原音频处理保持不变
- 仍须真实击败本局所有鼠王才算赢，时间到00不代杀鼠王

## 已验证与限制

- 掉落/回血/护盾/胜利规则269项，鼠王恢复33项，触控41项、DOM及原导出事件处理模拟30项；质量/坐标77项均通过
- 特效/合批几何、碰撞10项、10轮退出重启资源不增长验证通过。保留原始顶点/三角形，ArrayMesh法线编码导致最大0.006709度精度差，非简化模型
- 普通难度无--god完整模拟流程通过：受伤168、完成救援和击败鼠王。固定步长加速模拟不是实际计时/得分或手机性能证明
- 相同37演员/种子/窗口的真实云端原生Gatling测试，店内帧耗时中位数1143.8→689.6ms，店外1118.9→568.9ms；可见绘制调用减少约38–39%，三角形数量基本不变。修复版推进更多物理时间、发射更多子弹，工作量并非逐帧相同
- 云端是llvmpipe软件渲染，该压力场景依然很慢，不能声称已达到可玩FPS或证明手机30FPS。3D像素预算的窗口尺寸修正另有状态/坐标验证，未把它冒充成这次原生FPS测量结果
- 真正微信、其他手机Web/手机APK帧率、触控手感与听音仍未实测。修正了源码中可复现的触控问题，未证明它就是该微信设备的唯一根因。此轮没有针对手机音频另加假修复

## 使用

网页上传：PAW-SWAT-v0.11-Toy-Web.zip 根目录直接是index.html，只有9个运行文件；直接上传该完整ZIP。HTTP(S)/WebGL2必需，资源名无contenthash，更新后可能重下载。没有替用户上传Toy、发布或提交排行榜。

APK：PAW-SWAT-v0.11-Android-Test.apk 是独立测试版com.niko.pawswat.test，沿用v0.9/v0.10测试签名，版本代码11，可更新同测试应用；Android7+、ARMv7/ARM64、Vulkan能力要求保留。签名私钥不在源码中，自行换签名打包不能更新这个测试包。没有在真实手机安装测试。

历史Docs/Evidence保留并标版本；本轮四张截图在Evidence/Native-v0.11，来自真实原生压力夹具，原尺寸1180×812，WebP92。其他v0.8/v0.10图片是历史证据。

## 复现

外部QA在Docs/QA/v0.11，不应拷入网页目录。使用独立HOME/XDG目录、空排行榜URL。解压独立Web包后，例如：

    godot --headless --fixed-fps 60 --main-pack /path/Web/index.pck --script /path/Source/Docs/QA/v0.11/packed_qa_driver.gd -- --lb= --qa-harness=/path/Source/Docs/QA/v0.11/packed_victory_probe.gd

该外部夹具只加载发行包类/资源，不能证明浏览器/WASM运行。具体源、原生、模拟及警告见各QA报告。
