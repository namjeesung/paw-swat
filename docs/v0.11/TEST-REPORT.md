用户明确称它为“之前的试玩地址”。云端浏览器读取到的iframeHTML仍有旧版静音WAV/audioSession解锁脚本，声明PCK3,896,332字节、WASM38,057,390字节；v0.8交付为3,901,084/37,700,666字节，新v0.8桥接在该HTML中不存在。因此这个入口不能证明当前完整新构建的效果。

源码与对实际4.6.3导出JS的故障注入证明：AudioContext running后，异步worklet加载/节点失败仍可能没有混音输出且不会自动回退。此为风险机制，不是该Bilibili地址已证实的声音根因。本次保留v0.8处理，只增加默认隐藏的版本/音频/模块诊断，不声称新增回退修好了它。
