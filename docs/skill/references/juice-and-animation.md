# 手感与动画参考（Juice & Animation）

> 所有数值摘自代码。文件：`autoload/game.gd`（时间/震屏/转场）、`world/game_camera.gd`、`core/char_model.gd`、`core/fx.gd`、`actors/*.gd`、`world/{door,pickup,ground_guide,level}.gd`、`ui/*.gd`、`shaders/*`。
> 核心原则：**一个动作 = 画面 + 镜头 + 声音 + 时间 四路反馈同时触发**；UI 动画一律用真实时间。

---

## 1. 时间控制（`Game`）

```gdscript
const BT_SCALE := 0.25          # 子弹时间里世界的速度
const BT_PLAYER_SPEED := 0.6    # 子弹时间里玩家的相对速度

func _apply_scale() -> void:
	var s := 1.0
	if _bt_left > 0.0: s *= BT_SCALE
	if _hitstop_left > 0.0: s *= 0.04
	Engine.time_scale = s
```

| 机制 | 数值 | 说明 |
|---|---|---|
| 顿帧 hitstop | `time_scale × 0.04`；单次上限 **0.06s**；两次之间冷却 **350ms** | 计时用真实时间（`Time.get_ticks_usec` 差，单帧最多 0.1s）。冷却是性能大修时加的：加特林 + 一群僵尸时连续顿帧会让游戏「粘住」 |
| 谁会顿帧 | 匪徒被击倒 0.07、冲撞撞到人 0.06、破门 0.08、鼠王死亡 0.12（都被截到 0.06） | 玩家受伤、爆炸**不**顿帧（会打断操作） |
| 子弹时间 | 世界 ×0.25；玩家 `player_time_mult() = 0.6/0.25 = 2.4` 倍补偿 → 玩家实际 0.6 倍速 | 破门 1.9s、玩家死亡 1.5s、鼠王死亡 0.9s、终局空投 2.4s |
| 子弹时间附带 | 音乐总线 700Hz 低通打开（闷住）、全屏 shader 去饱和 + 色差 + 藏青暗角、敌人描边变 `RED`、镜头缩放 ×0.86、破门时显示「子 弹 时 间」横幅 | `bullet_time_changed` 信号统一分发 |
| 玩家子弹 | `Bullet` 用 `delta × player_time_mult()`，敌人子弹用原 delta | 子弹时间里自己的子弹飞得「正常」，敌人子弹慢 |
| 相机 / HUD | `rd = delta / max(time_scale, 0.01)`，再 `min(rd, 0.05)` | 顿帧/子弹时间中镜头和 UI 依然顺滑 |

## 2. 镜头（`GameCamera`）

| 参数 | 值 |
|---|---|
| 投影 | 正交，`size = 15.5`，臂旋转 `(-45°, 45°, 0)`，相机在臂上 z=60，near 0.5 / far 200 |
| 跟随 | `global_position.lerp(desired, 1 - exp(-7·rd))` |
| 前瞻 | `ahead = (瞄准点 - 玩家).limit_length(9) × (0.32 精瞄 / 0.2 平时)`；手机上瞄准点 = 玩家 + 朝向 × 2.5 |
| 震屏（trauma 模型） | `add_trauma(a)` 累加到 [0,1]；`shake = trauma²`；衰减 1.8/s；偏移 = `(sin(47t)·0.6 + sin(91t)·0.4) × shake × 0.7`（水平），`(sin(53t+1.3)·0.6 + sin(83t)·0.4) × shake × 0.7`（垂直） |
| 后坐踢 | `kick(v)` 累加，`lerp(0, 1 - exp(-18·rd))` 回中，投到 `h_offset / v_offset` |
| 缩放 | 精瞄 ×0.9、子弹时间 ×0.86、镜头指引 ×(1 - 0.12·w)，`lerp(1 - exp(-6·rd))` |
| 镜头指引 `focus(p, hold)` | 权重 `w` 以 +3/s 上升、hold 结束后 -2.5/s 回落，位置 `lerp(焦点, ease(w, -1.8))`；同时 HUD 电影黑边 70px |
| 震屏设置 | `Game.shake(a)` 乘以设置里的 `shake`（0/1）；`a ≥ 0.3` 时手机震动 `clamp(a×60, 15, 60)` ms |

常用震屏量：开枪 0.05 · 加特林 0.07 · 激光 0.04 · 冲撞 0.2 · 散弹 0.28 · 火箭 0.3 · 击倒 0.3 · 撞人 0.35 · 受伤 0.4 · 横幅 0.4 · 鼠王拍地 0.45 · 爆炸 0.5 · 鬼畜难度选择 0.5 · 变身后 0.7 · 破门 0.8 · 终局空投 1.0。

## 3. 角色程序化动画（`CharModel`）

层级：`CharModel`(yaw 朝向) → `pose`(倒地/翻滚/起跳) → `body`(上半身) + `feet`。

| 动画 | 公式 / 数值 |
|---|---|
| 步频 | `_walk += dt × (4 + 11 × move01)` |
| 颠步 | `body.y = |sin(walk)| × 0.07 × move01` |
| 左右摇 | `body.rot.z = sin(walk) × 0.075 × move01` |
| 前倾 | `body.rot.x = 0.1 × move01` |
| 迈脚 | 脚 z ±`sin(walk) × 0.17`，抬脚 `max(0, ±sin) × 0.07` |
| 呼吸（站立） | `scale.y × (1 + sin(3.2t) × 0.018 × (1 - move01))` |
| 尾巴 | `rot.y = sin(t × lerp(3, 13, wag)) × 0.35 × max(wag, 0.3)`；满血开心 wag=1，2 秒内受过伤 wag=0.2，敌人 0.25，上铐 0 |
| 蹲（掩体 / 蓄力） | `body.y -= crouch × 0.17`，`rot.x += crouch × 0.25`；crouch 用 `lerp(1 - exp(-14·dt))` 平滑 |
| 挤压 squash | `squash(v)` 设初值（命中 0.25、受伤 0.2、踹门 0.25、僵尸拍地 0.3），以 1.6/s 衰减；`sq = sin(squash × 9) × squash`，`scale = (1+sq, (1-sq)·breathe, 1+sq)` —— 一个带回弹的果冻感 |
| 闪色 flash | `flash(color, amount)`：所有登记材质 `emission = color × flash × 1.6`，flash 以 7/s 衰减。白=命中，红=受伤/敌人蓄力，橙=冲撞/完美换弹，青=上铐/获救，武器色=拿到神装 |
| 枪后坐 | `gun_kick` 设 0.13（步枪）/0.25（散弹）/0.3（火箭），1.4/s 衰减；`gun.pos = rest + (0, kick×0.3, -kick)` |
| 换描边 | `set_outline(color, xray)`：子弹时间敌人变红；上铐后变灰 `#55607A` |

### 翻滚（`player.gd`）
- 0.32s，速度 13.5 × `(0.5 + 0.5k)`（k 从 1 到 0，先快后慢），冷却 0.45s。
- `pose.rotation.x = (1-k) × TAU`（整个身体前空翻一圈），`pose.y = sin((1-k)π) × 0.25`（小跳）。
- 无敌：`roll_t > 0.03`（最后 0.03s 不无敌，避免「落地也免伤」）。子弹穿过时弹「闪避!」青字（0.4s 冷却）+ `dodge` 上滑音。
- 起跳烟尘 5 粒，落地烟尘 4 粒。
- 残影：每 0.045s 生成一个「胶囊 + 球」的半透明加色剪影（翻滚 `(1,0.8,0.5,0.35)`，冲撞 `(1,0.55,0.15,0.5)`），0.22s 淡出。

### 冲撞技能 Q
- 0.3s × 21m/s，冷却 7s；起手橙色冲击环 2.4、橙闪 0.6、震 0.2、`dash` 音。
- 撞到 1.2m 内的敌人：3 伤害 + 眩晕 1.3s（`body.rot.y = sin(stun×30)×0.25` 原地晃脑袋）+ 击飞 10 + 顿帧 + 震 0.35 + 12 粒橙火花。
- 撞到可破的门直接破门；撞到锁着的门：反弹 7、`bonk`（音高 0.7）、震 0.3、toast「门锁死了 —— 先清理店面！」。

### 倒地 / 醒来 / 上铐（`enemy.gd`）

| 动作 | 动画 |
|---|---|
| 晕倒 | `pose.rot.x → -π/2`（0.3s，`TRANS_BOUNCE EASE_OUT` 摔地弹两下），`pose.y → 0.3`；击退 6；3 颗黄色发光五角星在头顶半径 0.38 绕圈（5 rad/s），最后 3 秒闪烁；「击倒!」黄字 72；8 粒烟尘 |
| 倒计时标签 | Label3D 快乐体 56：`> 4s` 青色「可上铐 Ns」；`≤ 4s`「快醒了! Ns」红/黄每 0.2s 交替 |
| 醒来 | `pose → 0`（0.25s `TRANS_BACK`），血量回 50%，紫色「醒了!」，`wake` 上滑音 |
| 上铐 | `pose.rot → 0`、`pose.y → -0.1`（0.25s BACK）、蹲下、手铐可见、描边变灰、青闪、青色冲击环 1.8、「上铐!」青字 72、`cuff` 双响金属音 |
| 警觉「!」 | Bungee 120 橙色 Label3D：缩放 0.2 → 1.3（0.12s BACK OUT）→ 1.0（0.08s）→ 停 0.7s → 0（0.12s）；并把 7m 内同区域队友也惊动 |

### 玩家倒地
`pose.rot.x → -π/2`（0.35s BOUNCE）、`y → 0.3`，子弹时间 1.5s，任务失败横幅。

## 6. 关卡事件动画

### 破门（`door.gd`）
1. 玩家按 E：`action_lock 0.28s`、瞬间转向门、向门冲 5、挤压 0.25、`swing`，**0.12s 后**才真正破门（给「抬脚」一点时间）。
2. 门板 `MeshInstance` 被搬到一个新建的 `RigidBody3D`（质量 25）里：冲量 `离开方向 × 260 + 上 × 80`，随机扭矩 ±30/±40；4 秒后冻结。
3. 18 粒木色火花、14 粒烟尘、橙色冲击环 4.0、`breach` + `slowmo`、震 0.8、顿帧、子弹时间 1.9s。
4. 子弹时间中：屏幕去饱和、敌人描边变红、「子 弹 时 间 / — BREACH & CLEAR —」横幅（透明度 5/s 渐显，缩放 `1 + (1-a)×0.3` 从大缩到正常）。
5. 破门前：可破的门自发光橙色呼吸 `0.25 + 0.22·sin(5t)`；门上方一个橙色发光三棱锥上下浮 0.18（4Hz）、自转 2 rad/s。

### 掉落物 / 光柱（`pickup.gd`）
- 武器箱：金色 `#FFD25A` 箱体 + 藏青腰带；**光柱** = 半径 0.32/0.42、高 7m 的发光圆柱（武器色，alpha 0.22）；箱子上方 1.5 倍大的武器模型自转 2 rad/s、上下浮 0.12（3Hz）；Label3D「神装 · 散弹」；武器色点光源。
- 空投下落：从高度 9（回血罐头 8）以 0.6s `TRANS_QUAD EASE_IN` 砸下（加速度感）→ 落地 10 粒烟尘 + 黄色环 2.2 + `stamp` 重击音 + 震 0.25。
- 拾取：1.5m 内自动；缩到 0.01（0.18s，BACK EASE_IN —— 先微微放大再吸走）。

### 地面箭头（`ground_guide.gd`）
```gdscript
var offset := fmod(_t * 2.2, SPACING) + 0.9      # 2.2 m/s 向前流动，从玩家前 0.9m 开始
var fade := clampf((next_at - 0.9) / 1.5, 0.0, 1.0) * clampf(1.0 - float(idx) / MAX_ARROWS, 0.25, 1.0)
```
间距 1.1m，最多 22 个，HDR 橙色 `(2.0, 1.1, 0.3, 0.85)` 不受光，路径每 0.35s 重算一次。

### 僵尸出生 / 消失
- 出生：模型从 `y = -1.3 × scale` 以 0.45s `TRANS_BACK EASE_OUT` 钻出 + 绿色烟尘；出生后 0.5s 才开始行动，前 0.25s 不受伤害。
- 消失：身体 0.1s 压扁成 `(1.4, 0.2, 1.4)` 倍 → 删除；绿色烟尘 5（鼠王 24 + 30 粒绿火花）；白色小幽灵 0.85 透明，1.0s 内上浮 2.2（SINE OUT）并缩到 0.2；`splat` 音高随机 0.9~1.3。

### 环境
- 警车红蓝灯：每 0.25s 交替（3.5 / 0.2 能量 + 灯泡显隐）。
- 员工休息室灯：每 2.3s 闪暗 0.12s（破门后稳定）。
- 自动门：玩家进入 3.2m 内两扇玻璃门滑开到 ±2.3（`1 - exp(-10·dt)`）。
- 僵尸潮：环境光 1.5s 变成 `#6E9E86`，雾 `#3E7A55` 密度 0 → 0.004（2s）。

## 7. 高潮演出

### 7.1 像素风变身动画（`ui/cutscene.gd`）

技术要点：
```gdscript
_vp = SubViewport.new()
_vp.size = Vector2i(320, 180)
_vp.disable_3d = true
_vp.canvas_item_default_texture_filter = Viewport.DEFAULT_CANVAS_ITEM_TEXTURE_FILTER_NEAREST
# 全屏 TextureRect 放大，NEAREST + STRETCH_KEEP_ASPECT_CENTERED（宽屏两边留黑，不裁切）

func _process(_d):
	_acc += minf((now - _last) / 1e6, 0.1)     # 真实时间
	while _acc >= 1.0 / 30.0:                 # 30fps 步进，「一拍一拍」的手绘感
		_acc -= 1.0 / 30.0
		_f += 1
		_on_frame(_f)
```
- 播放期间 `get_tree().paused = true`，Cutscene 自身 `PROCESS_MODE_ALWAYS`；排行榜计时也因此不算这 3.6 秒。
- 像素层里的图形用 `draw_circle(..., antialiased=false)`、`draw_line(..., false)` 保持硬边。

分镜（共 108 帧）：

| 帧 | 画面 | 声音 / 闪白 |
|---|---|---|
| 0–6 | 上下黑边从 0 推到 7% 屏高（全分辨率层） | `transform`（120→900Hz 锯齿上扫 + 渐强噪声） |
| 0–62 | 藏青底 + 28 条橙/浅藏青放射速度线，每帧旋转 0.06rad，内端半径 36 + 跳动 | — |
| 3–15 | 豆包头像从 x=-80 滑到 96，`ease(k, -2.4)` | — |
| 20–30 | 右眼四角星闪光，大小 `sin(k·π) × 12` | — |

### 8.1 警戒线转场（`Game._tape`）

- 进：0.32s `CUBIC EASE_OUT`，每条延迟 `i × 0.06`；同时藏青遮罩 0.3s 渐显（延迟 0.1）。

## 9. 全屏 shader（`screen_fx.gdshader`）

```glsl
float ca = 0.004 * bullet_time + 0.003 * hurt;          // 色差
vec3 bt = mix(col, vec3(lum) * vec3(0.85, 0.95, 1.15), 0.72);   // 去饱和偏冷
col = mix(col, bt, bullet_time);
float vig = smoothstep(0.45, 1.05, d);                   // d = length(dir * vec2(1.6, 1.0))
col = mix(col, vec3(0.05, 0.08, 0.2), vig * 0.65 * bullet_time);
float red = vig * (low_hp * (0.55 + 0.25 * pulse)) + smoothstep(0.3, 1.0, d) * hurt * 0.7;
col = mix(col, vec3(0.75, 0.05, 0.08), clamp(red, 0.0, 0.85));
```
- 子弹时间参数以 4/s 渐入渐出；只有任一参数 > 0.001 时该 ColorRect 才 `visible`（省一次全屏采样）。

## 10. 缓动选择速查

| 场景 | 缓动 |
|---|---|
| 弹出、入场、悬停放大、印章以外的「出现」 | `TRANS_BACK + EASE_OUT`（带过冲回弹） |
| 离场、滑出 | `TRANS_CUBIC + EASE_IN` |
| 转场胶带进场、相机类平移 | `TRANS_CUBIC + EASE_OUT` |
| 倒地 | `TRANS_BOUNCE + EASE_OUT` |
| 重物砸下（空投、印章、FIRE!） | `EASE_IN`（`TRANS_QUAD` 或默认 LINEAR）= 加速 |
| 吸走消失（拾取） | `TRANS_BACK + EASE_IN`（先鼓一下再缩没） |
| 幽灵飘走 | `TRANS_SINE + EASE_OUT` |
| 持续跟随（相机、残血、连杀缩放、提示卡滑入） | 帧率无关指数平滑 `lerp(a, b, 1 - exp(-k·dt))`，k = 6~20 |
| 自绘控件里的一次性脉冲 | 设变量 = 1，每帧 `max(0, v - dt × 速率)`，绘制时用 v 或 `ease(v, 负数)` |
