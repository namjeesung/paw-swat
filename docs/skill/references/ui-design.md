# UI 设计参考：「贴纸 / 警局档案」设计语言

> 数值全部摘自 `game/scripts/core/pal.gd`、`style.gd` 和 `game/scripts/ui/*.gd`。
> 这一套 UI **没有一张图片素材**：面板是 `StyleBoxFlat`，图标/头像/血条是 `_draw()`，背景纹理是 canvas shader。

---

## 1. 设计原则

1. **每个界面都是一件「实物」**：软木任务板、拍立得照片、便利贴、警员证、投影幕、对讲机、狗牌、报纸、印章、警戒线胶带。玩家一眼就懂「这是什么」，也自带可爱的手工感。
2. **贴纸感三件套**：
   - 粗描边：`Pal.INK #141A26`，面板 3~6px，按钮 4px，按钮底边 9px（厚底，按下变 4px = 「按下去」）。
   - 偏移硬阴影：同形状、`Color(0,0,0,0.3~0.45)`、向右下偏 `(6~14, 8~18)`，**不模糊**。
   - 轻微倾斜：纸张/卡片 `rotation` ±1.5°~4°，悬停时转正（`base_rot × 0.2`）。
3. **暖色 = 我方 / 可操作，紫色 = 敌人，青色 = 人质/安全，红色 = 危险**。颜色在 3D 描边、UI、文字高亮里含义一致。
4. **所有出现都有动画**：没有任何面板「啪」地瞬间出现；统一用 `TRANS_BACK + EASE_OUT`（带回弹）做入场，`TRANS_CUBIC + EASE_IN` 做离场。
5. **时间无关**：UI 动画用真实时间（`set_ignore_time_scale(true)` 或 `HudWidgets.real_delta()`），子弹时间、顿帧里 UI 不变慢；暂停时还要动的 Tween 设 `TWEEN_PAUSE_PROCESS`。

## 3. 字体（`core/style.gd`）

| 函数 | 字体 | 用于 | 典型字号（1920×1080 画布） |
|---|---|---|---|
| `Style.title_font()` | 站酷快乐体 ZCOOL KuaiLe | 标题、按钮、名牌、横幅、跳字「击倒!」 | 大标题 96~132，横幅 110，按钮 28~56，标签 22~36 |
| `Style.body_font()` | 思源黑体 SC Medium（子集） | 正文、说明、提示卡正文 | 18~30 |
| `Style.bold_font()` | 思源黑体 SC Black（子集） | 结算数值、对讲机 `[b]` | 25~26 |
| `Style.num_font()` | Bungee | 数字、英文招牌、计时、弹药、伤害数字、FIRE! | 计时 34，弹药 66（每枪 +10 弹跳），FIRE! 220 |

- 标题和数字字体缺中文字时自动回落到思源黑体 Black（`f.fallbacks = [NotoSansSC-Black]`）。
- 思源黑体是**子集化**的：GB2312 一级 3755 字 + ASCII + 常用全角标点 + 扫描所有 `.gd` 里出现的字符；可变字体实例化为 wght 500 / 900 两份。改文案出现生僻字时要重跑子集脚本。
- 全局主题字体在 `project.godot` 里设成 `NotoSansSC-Medium.ttf`（`gui/theme/custom_font`），保证没手动设字体的控件也是中文可读的。
- 文字描边：深色背景上的亮字统一加 INK 描边（`Style.label(text, size, color, font, outline=8~22)`），保证在 3D 场景上也清楚。

## 4. 画布与布局规则

- `project.godot`：`viewport 1920×1080`，`stretch/mode = canvas_items`，`aspect = expand`。窗口默认 1440×810。
- **expand 的含义**：短边固定 1080（或 1920），多出来的长度变成额外可用区域。20:9 手机 = 宽约 2400；4:3 平板 = 高约 1440。
- 两种布局方式：
  1. **居中 board**（菜单、简报、结算、排行榜）：一个 1920×1080 的 `board` 控件，锚点 (0.5,0.5)，offset ±960/±540，里面全用绝对坐标摆。宽屏时两边露出全屏背景（软木 shader 铺满整个窗口）。
  2. **锚点贴边**（HUD、暂停）：`Hud._anchor(c, ax, ay, x, y, w, h)` 把控件锚在某个角/边，再给像素偏移。

```gdscript
func _anchor(c: Control, ax: float, ay: float, x: float, y: float, w: float, h: float) -> Control:
	c.anchor_left = ax; c.anchor_right = ax
	c.anchor_top = ay; c.anchor_bottom = ay
	c.offset_left = x; c.offset_top = y
	c.offset_right = x + w; c.offset_bottom = y + h
	return c
```

- 背景 shader 的 `aspect` 参数要在 `resized` 里更新，否则宽屏下颗粒被拉伸。
- 手机竖屏（`高 > 宽 × 1.05`）时盖一层「请把手机横过来玩」（layer 120）。

## 6. 组件库

### 6.1 `StickerButton`（`ui/sticker_button.gd`）

| 状态 | 样式 |
|---|---|
| normal | `Style.box(bg, radius 16, border 4, INK)`，`border_width_bottom = 9`，内边距 左右 30 / 上 8 / 下 10 |
| hover / focus | 底色 `lightened(0.12)`；Tween 放大 1.06 + 旋转 -1.5°（0.14s，BACK OUT）；`ui_hover` 音 -10dB |
| pressed | 底色 `darkened(0.08)`，底边 9 → 4，内容下移 5px（上 13 / 下 5）= 「按下去」；`button_down` 时 `ui_click` |
| disabled | 底色 35% 透明 |
| focus 环 | 不填充、3px 奶油色描边、外扩 6px、圆角 20（手柄/键盘导航可见） |

| kind | 底色 | 文字 |
|---|---|---|
| `primary` | ORANGE | INK |
| `secondary` | NAVY_LIGHT | CREAM |
| `ghost` | CREAM | INK |
| `danger` | RED | CREAM |

- 字体：站酷快乐体，字号由构造参数给（28~56）。
- `pivot_offset` 在 `resized` 时设为中心，缩放才不跑偏。
- Tween `set_ignore_time_scale(true)` + `TWEEN_PAUSE_PROCESS`：暂停菜单里也能动。
- 每个界面默认焦点放在主按钮上（`grab_focus.call_deferred()`），Enter 键 = 主操作，Esc = 返回。
- 样式在 `_init` 里一次性设好：要切换 kind（如 tab 高亮）就**重建按钮**。

### 6.2 键帽 `Style.keycap("E")`

奶油底、圆角 6、2px INK 描边、**底边 5px**（立体键帽），Bungee 字。HUD 里画在 `_draw()` 中的版本是 `HudWidgets.keycap()`，按字符长度自动算宽（≤2 字用 Bungee，否则用黑体）。

### 6.3 狗牌血条 `HudWidgets.DogTag`

- 整体：460×170，钢色 `STEEL` 圆角 38、5px INK 描边，左边一个孔 + 10 颗斜挂的珠链（每颗 INK 4.2 + STEEL 2.6 两层圆）。
- 待机：整体 `rotation = -0.035 + sin(t×1.4)×0.006`（轻轻晃）。
- 受击 `hit()`：`_shake = 1`，每帧随机偏移 ±9px × shake，额外旋转 +0.05×shake，衰减 3/s。
- 头像：r=62 INK 圈 + r=57 NAVY（火力强化时 ORANGE_DARK）+ `Portrait.draw_face(..., "shiba")`。
- 名字「豆包」快乐体 42 + 编号「PAW-0427」Bungee 17。
- 血条：10 段**平行四边形**（每段顶边右移 7px，段间距 4），先画 `#2A3350` 底，再画白色「残影血」（从旧血量以 45hp/s 追到新血量），再画当前血；颜色 >60% GREEN、>30% YELLOW、否则 RED 且 `lerp(WHITE, 0.25+0.25·sin(12t))` 闪烁。
- 数字：当前血 Bungee 34 + 「/ 100」17 半透明。
- 状态：掩体时右下画青色盾牌 +「掩体」；火力强化时「火力强化」橙字。

### 6.4 罐头弹药 `HudWidgets.AmmoPanel`

```gdscript
static func rich(text: String) -> String:
	return text.replace("[", "[lb]").replace("{", "[color=%s][b]" % KEY_COLOR).replace("}", "[/b][/color]")
```

### 6.7 目标药丸 `ObjectiveBanner`

- 宽度按文字自适应：`120 + 标题宽 + (进度宽 + 36)`，高 64，NAVY 95% 圆角 32（药丸形）+ 4px 描边 + 偏移阴影。
- 左侧橙色圆角标签「目标」（96 宽）。
- 标题快乐体 36 奶油色，进度 Bungee 30 橙色。
- 标题改变：`_pop` 从 0 以 4/s 回到 1，缩放 `0.85 + 0.15·ease(pop, -2)`；同时白色闪光 `_flash=1`（45% 白覆盖，衰减 2.5/s）+ `radio` 音。进度改变只闪 0.7。

### 6.8 连杀计数

- Bungee 84 黄字 `×N` + 快乐体 30「连 杀」；≥3 连才显示。
- 每次击杀：缩放设 1.5，`lerp(ONE, 1 - exp(-12·dt))` 回弹；2.6 秒内无击杀清零。

## 8. 「在代码里搭界面」的写法约定

1. 每个界面是一个 `extends Control` 的类，`_ready()` 里 `Style.full_rect(self)` 然后逐个 `add_child`。
2. **所有颜色只从 `Pal` 取**，所有字体/面板/标签只从 `Style` 工厂取：`Style.label()`、`Style.panel()`、`Style.box()`、`Style.keycap()`、`Style.shader_rect()`。
3. 复杂的、要动画的小部件写成内部类 `class X extends Control`，`_process` 里改状态 + `queue_redraw()`，`_draw()` 里画。
4. 装饰性控件一律 `mouse_filter = MOUSE_FILTER_IGNORE`（`Style.label/panel` 默认如此），只有真正可点的才 STOP。
5. 投影/阴影用「先画一个偏移的半透明黑色同形状」实现，`Style.box(..., shadow)` 只在需要柔和阴影时用。
6. 文字高亮在对白里用 BBCode（`[color=#FFB347]…[/color]`），在提示卡里用 `{…}` 标记再转换，避免策划/文案写 BBCode。
7. 每个可交互界面：默认焦点、Enter 确认、Esc 返回、安卓返回键（`Game._notification`）都要处理。
