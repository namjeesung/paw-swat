# 音频参考：全部代码合成的音效与音乐

> 文件：`game/scripts/autoload/sfx.gd`（合成器 + 播放）、`game/scripts/tools/bake_audio.gd`（离线烘焙）、`game/assets/sfx/*.wav`（烘焙产物）。
> 没有任何录音素材。所有声音由三块积木拼出来：**音调（tone）**、**噪声（noise）**、**钟声（bell）**。

---

## 1. 架构

```
Sfx (autoload, PROCESS_MODE_ALWAYS)
 ├─ 28 × AudioStreamPlayer  → 总线 "SFX"   （轮询复用：_next = (_next + 1) % 28）
 └─ 1 × AudioStreamPlayer   → 总线 "Music" （总线上挂 700Hz 低通，默认关闭）
总线：Master ← SFX、Music（都在代码里 AudioServer.add_bus 创建）
```

| API | 说明 |
|---|---|
| `Sfx.play(id, vol_db = 0, pitch = 1, pitch_rand = 0.05)` | 取下一个播放器播放；音高 `pitch × (1 ± pitch_rand)`，**默认 ±5% 随机**，连续开枪不会「机关枪复读」 |
| `Sfx.music(track)` | `"menu" / "combat" / "wave" / ""`；同一首正在播则不重启；音量 -6dB |
| `Sfx.muffle(on)` | 打开/关闭 Music 总线的低通 → 子弹时间「闷住」 |
| `Sfx.set_volume(bus, linear)` | `linear_to_db`，≤0.001 直接静音；设置存 `user://settings.cfg`（默认 SFX 0.85、Music 0.55） |

播放端的 `_stream(id)`：先查缓存；没有就现场 `_synth(id)` → `_to_wav()`（16 位、单声道、22050Hz、`×32000` 量化；`music_*` 设为 `LOOP_FORWARD`）。

> ⚠️ 这个方法最早叫 `_get(sound)`，和 `Object._get(property)` 虚函数重名，等于重写了 Sfx 节点的属性读取，导致奇怪的错误。**脚本里不要用引擎虚函数名当普通方法名。**

## 2. 合成积木

```gdscript
const RATE := 22050

## 噪声：一阶低通 y += (rand - y) * lp；lp 越小越闷；hp=true 时取差分 = 高通（清脆的「咔」）
static func _add_noise(b, start, dur, amp, env_k, lp := 1.0, hp := false)
	# 包络：amp * exp(-t * env_k)

## 音调：频率从 f0 指数滑到 f1；wave 0 正弦 1 方波 2 三角 3 锯齿
static func _add_tone(b, start, dur, amp, f0, f1, env_k, wave := 0, attack := 0.003)
	# f = f0 * pow(f1 / f0, t / dur)
	# env = exp(-t * env_k) * min(1, t / attack)

## 钟声：基频 + 2.01 倍（半幅、衰减 6）+ 3.02 倍（1/4 幅、衰减 9），轻微失谐 = 金属感
static func _add_bell(b, start, dur, amp, f)

static func _note(semi_from_a4) -> float:   # 440 * 2^(semi/12)
```

设计口诀：
- **低频正弦大下滑**（如 170 → 45Hz）= 「砰」的体感 / 炮口冲击。
- **低通噪声 + 中速衰减** = 火药爆燃、爆炸的「轰」。
- **高通噪声 + 极快衰减（60~120）** = 机械「咔哒」、瞬态。
- **方波 / 锯齿** = 电子、复古、UI；**三角** = 柔和的 UI 和旋律。
- **向上滑音** = 正反馈（闪避、醒来、拾取）；**向下滑音** = 负反馈 / 冲击。
- **琶音（大三和弦逐个错开 50~60ms）** = 「叮咚」奖励感。
- 包络 `env_k` 越大越短促：UI 30~80，枪声 16~26，爆炸 3.5~5，持续音 0.5~2。

### `shout_fire`：不用人声的「喊叫」
```gdscript
# 0.07~0.62s 之间：基频 300 → 210Hz 下滑 + 2% 颤音（40Hz）
var saw := 2.0 * x7 - 1.0                                      # 锯齿 = 声带
var form := sin(TAU * ph7 * lerpf(3.0, 2.0, k7)) * 0.5 + sin(TAU * ph7 * 7.0) * 0.2   # 「共振峰」从 3 倍滑到 2 倍 =「FAI → YAH」的元音变化
var env7 := minf(1.0, (t7 - 0.07) * 30.0) * (1.0 - k7 * 0.6)
b[i] += (saw * 0.35 + form * 0.45) * env7 * 0.8
# 前面一段 90ms 高通噪声 = 「F」的气流；底下一个 90→35Hz 正弦 = 胸腔冲击
```
思路：锯齿波当声带，叠两个随时间移动的谐波当「元音共振峰」，噪声当辅音。足够让玩家听出「喊了一嗓子」，又和可爱画风一致。

## 4. 音乐生成

三首都是 **4 小节循环**，用和弦表 / 低音型 / 鼓点规则直接写进缓冲区，整段烘焙成一个循环 WAV。

### 菜单 `music_menu`：lo-fi，84 BPM（约 11.4 秒一循环）
- 和弦（每小节一个）：**Am – F – Dm – G**，每个和弦 4 个音，三角波（幅 0.07，attack 0.15s，k0.5 = 很软的 pad）+ 高八度正弦（幅 0.03）。
- 贝斯：和弦根音再低两个八度（A1 = 55Hz）正弦，第 1 拍长音 + 第 3.5 拍切分。
- 鼓：1、3 拍底鼓（正弦 110→42Hz，k14）；2、4 拍闷军鼓（低通噪声 lp0.35）；每个反拍一个很轻的高通踩镲。

### 战斗 `music_combat`：118 BPM（约 8.1 秒）
- 根音序列 A – A – F# – B（`roots = [-24,-24,-27,-22]`）。
- 八分音符低音型 `[0, 0, 12, 0, 3, 0, 10, 7]`（根、根、八度、根、小三度、根、小七度、五度）：锯齿（幅 0.2）+ 低八度正弦（0.14），每音 0.45 拍（断奏）。
- 每个八分音符一个踩镲（强拍 0.06、弱拍 0.035）。
- 底鼓：1、3 拍，奇数小节第 4 拍加一下；军鼓：2、4 拍（噪声 + 三角 220→160 的「啪」）。
- 奇数小节第 3.5 拍一个方波「stab」点缀。

### 僵尸潮 `music_wave`：150 BPM（6.4 秒），更快更燃
- 根音 A – A – C – G；低音型 `[0, 12, 0, 10, 0, 7, 0, 12]`（八度跳跃 = 推进感），锯齿 + 方波。
- **每拍底鼓**（four-on-the-floor），2、4 拍军鼓，反拍踩镲。
- 主旋律：每小节一个长音（根 + `[12, 15, 19, 17]` 半音），第 3 拍再来一次降约 2 个半音（×0.89）——简单的号角式动机。

### 切换时机
| 场景 | 音乐 |
|---|---|
| 主菜单、简报、排行榜、结算 | `menu` |
| 进入关卡 | `combat` |
| 僵尸来袭 | `wave` |
| 终局空投 / 失败 | 停止（让爆炸和胜利/失败旋律独占） |

## 5. 混音习惯（`play()` 的 vol_db）

| 类别 | 典型音量 |
|---|---|
| 高频重复（玩家枪声） | -8dB，音高 ±8%；加特林 -10dB |
| 命中 / 敌人枪声 | -7 / -10dB |
| 打字、type | -16dB |
| UI 悬停 / 点击 | -10 / -4dB |
| 重要事件（破门、爆炸、印章、喊叫、FIRE） | 0 ~ +2dB，`pitch_rand = 0`（重要音不随机） |
| 环境（僵尸呻吟） | -14dB（鼠王 -4dB） |
| 多个同类事件同时发生 | 主动削减：终局 60% 的僵尸静音消失；激光音节流 0.16s |

- 全局：音乐默认 0.55、音效 0.85；音乐比音效低是为了让反馈音永远听得清。
- 子弹时间：音乐总线低通 700Hz（`Game.bullet_time()` 打开、结束或 `reset_time()` 时关闭）。当前代码里暂停菜单只做画面模糊、不闷音乐；如果想要「暂停 = 闷音」，在 `PauseMenu.open/close` 里调 `Sfx.muffle(true/false)` 即可。

## 6. 烘焙为 WAV（解决运行时卡顿）

问题：GDScript 逐采样循环很慢，第一次播放 `music_menu`（25 万个采样 × 多层叠加）或 `breach` 时会卡几十到上百毫秒。

`scripts/tools/bake_audio.gd`（`extends SceneTree`，命令行脚本）：
```gdscript
func _initialize() -> void:
	seed(20261006)                                   # 固定随机种子：每次烘焙结果一致，diff 干净
	var synth: Node = load("res://scripts/autoload/sfx.gd").new()
	for n in NAMES:                                  # 50 个 id（47 音效 + 3 音乐）
		var data: PackedFloat32Array = synth._synth(n)
		var w: AudioStreamWAV = synth._to_wav(data, n.begins_with("music_"))
		w.save_to_wav("res://assets/sfx/%s.wav" % n)
	synth.free()
	quit()
```
运行：
```bash
godot --headless --path game -s res://scripts/tools/bake_audio.gd
godot --headless --path game --import        # 让编辑器生成 .import（首次或新增文件后）
```
运行时 `Sfx._preload_baked()` 在 `_ready` 里遍历 `res://assets/sfx`（兼容导出后的 `.import/.remap` 后缀），全部 `load()` 进缓存；音乐文件重新设置 `LOOP_FORWARD` 和 `loop_end`（导入的 WAV 默认不循环）。

**改了合成代码一定要重新烘焙**，否则游戏里听到的还是旧 WAV（缓存优先）。新加音效：在 `_synth` 的 `match` 里加分支 + 在 `bake_audio.gd` 的 `NAMES` 里加名字 + 重新烘焙。

## 7. 新增一个音效的流程（示例）

1. 想清楚「它像什么」：如「拾取补给」= 正反馈 → 向上琶音；短 → 0.4s。
2. 在 `_synth` 里写：
   ```gdscript
   "heal_up":
       b = _buf(0.4)
       for i in 3:
           _add_tone(b, i * 0.05, 0.25, 0.25, _note(7 + i * 5), _note(7 + i * 5), 9.0, 2)
       _add_noise(b, 0, 0.03, 0.3, 100.0, 1.0, true)
   ```
3. `NAMES` 加 `"heal_up"`，烘焙，`--import`。
4. 调用处 `Sfx.play("heal_up", -4.0, 1.0, 0.0)`。
5. 跑 `--autotest` 听一遍（或单独写个小场景循环播放）对比相邻音效的响度。
