# v0.12.2：桌面输入识别与匪徒消散

## Edge / 键鼠 / 触屏

旧代码把系统“支持触屏”或 maxTouchPoints > 0 直接当成移动端模式。Windows电脑和二合一设备也可能报告这些能力，导致游戏显示手机摇杆，并让虚拟输入接管玩家、绕过键鼠。

本版不按浏览器品牌硬编码、不按窗口尺寸猜设备：启动采用移动设备/iPad/主指针信息，之后以真实手指、鼠标和游戏按键切换。触摸生成的兼容鼠标事件不会反复切换模式。桌面隐藏虚拟按钮时，它们不继续逐帧接管输入；真正触摸后仍可使用原摇杆和按钮。旋转、取消触摸、暂停设置和切回键鼠均有回归覆盖。未新增物理手柄映射。

## 匪徒规则（经用户确认）

- 血量归零立即永久制服；不再有14秒醒来、倒地倒计时或必须按E上铐
- 同一瞬间关闭AI/物理回调、碰撞和攻击，清空路径，退出敌人查询列表
- 只有4个轻量尘粒及约0.25秒缩小消散，然后真正释放整个节点；不会留下隐藏尸体。该消散时间不随子弹时间拉长
- 原击倒100分＋永久制服150分合为250分；每个敌人只记一次，指定武器/手雷掉落也只处理一次。保留全员制服300分奖励，不新增额外奖励
- 存档字段 cuffs 为兼容旧格式保留，界面含义改为“永久制服”
- 任务进度用独立累计计数，释放演员后仍能开门、解救人质、进入原僵尸潮。鼠王击杀门槛/60秒规则不变
- 修正已消散敌人的触屏锁定和飞行中子弹射手引用，避免访问已释放节点

这次规则调整会影响通关用时。Toy公共榜仍保留旧版成绩，不自动删榜、重置榜单或上传旧成绩；跨版本用时不是完全相同规则的比较。
