# v0.12.1 僵尸潮切换优化

## 改动

- 场景从首次渲染起保持雾效着色器路径，但初始雾密度和高度雾密度为零，因此前半关仍然清晰。僵尸潮开始只渐变雾密度，不再突然切换所有场景材质的雾效变体。
- 将僵尸来袭横幅、FIRE 大字和变身动画用到的精确字体/字号/描边组合，提前分帧处理到字体缓存和纹理图集；使用实际绘制路径，包含字形排版、回退字体、画布缩放和子像素位置。每帧最多八个单字形填充/描边任务、2ms 软预算；单次引擎字形调用不可中断，不承诺硬实时上限。没有降低字号或描边质量。
- 不修改潮开始的剧情时间、60秒规则、刷怪数值、鼠王击杀门槛、护盾/回血预算、移动/卡住恢复规则、音频或微信输入修复。
- 修正开发机器人验收条件：旧脚本仅凭“救过人质”便返回成功，现在输出真实结算数据，并依照结算 success 退出。测试脚本不进入发行包。

## 已运行的验证

使用官方 Godot 4.6.3。新增切换回归测试检查缓存已填充、分帧执行、退出关卡时安全取消、零密度开场、原定时间开始潮、空投、最终雾密度、60秒与鼠王击杀门槛。既有护盾、回血和文字布局回归同时执行；最终结果：切换37/37（lite 30Hz和hq 60Hz）；护盾43/43；回血预算110/110；提示布局9/9。另完成鬼畜难度“跳过前半关、无敌”僵尸潮流程：3鼠王出现并通过真实 success=true 结算。该流程不是无无敌普通难度通关证明。

独立 CPU 字形探针（headless，同一进程冷/热缓存）：110px 中文横幅首次约4.27ms，再次0.017ms；220px FIRE 首次约4.04ms，再次0.023ms。这只证明字体缓存的CPU重复工作被移出首次呈现，不代表网页/手机帧率。

## 验证边界

- 此环境原生显示和 Chromium 被本地 socket 限制阻止，未获得有效的 WebGL/真机渲染帧时间。不能保证用户报告的1–2秒卡顿已经完全消失，也不宣称新的FPS。
- 变身动画原本会主动暂停游戏约3.6秒，这是保留的演出，与线程长帧卡顿不同。
- 手机微信/Safari音频、实际触摸、真实GPU表现仍需目标设备验收。没有通过降低画质、改变游戏时钟或延后僵尸潮隐藏卡顿。

## 复现回归

运行项目导入，再运行：

    godot --headless --path GodotProject res://scripts/test/qa/horde_transition_regression.tscn -- --lite
    godot --headless --path GodotProject res://scripts/test/qa/shield_regression.tscn -- --lite
    godot --headless --path GodotProject res://scripts/test/qa/heal_budget_regression.tscn -- --lite
    godot --headless --path GodotProject res://scripts/test/qa/heal_tip_metrics.tscn -- --lite

将 --lite 换成 --hq 可检查60Hz配置。测试均禁用线上成绩提交。运行全程开发机器人时显式加 --lb=；--god 仅能用于流程验证，不能视为普通难度可通关证明。
