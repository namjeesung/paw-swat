# 《爪爪特警 PAW S.W.A.T.》剧本 & 设计草案 v0.1

> 2.5D · 45° 等距俯视 · 第三人称双摇杆射击 · 猫狗特警 vs 浣熊匪帮
> 本文档为第一版剧本，供评审。确认方向后再进入原型开发。

---

## 一、一句话卖点

**“毛茸茸的手感，硬核的破门。”**
可爱的猫狗特警，打出 SWAT 式战术破门 + 动作射击的爽快感——每一次开枪、翻滚、踹门都要有分量。

---

## 二、世界观

**毛绒市（Fluffton）**，一座由动物居民组成的港口城市。
城市最重要的资产是位于市中心的 **「金罐储备库」**——全城的猫罐头、狗骨头、冻干零食都储存在这里，是毛绒市经济的命脉。

最近，一个叫 **「黑眼圈帮」** 的浣熊匪帮崛起。他们天生自带“蒙面”，行动诡秘，抢劫便利店、走私码头货物、绑架市民。
毛绒市警局为此组建了一支精英小队：**P.A.W. 特警队**（Precision Assault Whiskers）。

## 四、剧情（5 章）

### 序章 · 午夜便利店 （教学关）
> 凌晨 2 点，“喵喵 24h 便利店”被抢。

- 豆包第一次独立出勤，局长在耳机里教学：移动 → 瞄准射击 → 翻滚躲子弹 → 换弹 → 掩体。
- 小毛贼们在货架间乱窜，最后一个浣熊打手挟持了店员仓鼠 **小米**。
- **第一次破门教学**：踹开员工休息室门，子弹时间中击倒打手，救出小米。
- 结尾：打手被铐时冷笑：“你们……什么都不知道。老K会来接我的。”

> **v0.3 新增高潮：僵尸鼠来袭**
> 救出小米后，仓库里黑眼圈帮偷运的「实验罐头」泄漏冒出绿烟，一大波**僵尸鼠**（可爱款：薄荷绿圆滚滚、创可贴、缝线小嘴）从街道和冰柜后面涌进来。
> 警方空投「神器 · 罐头加特林」——拾取后进入 **像素风变身特写**（零件飞来组装 → 神器装备 → 大喊 **FIRE!**），坚守 60 秒，期间出现「僵尸鼠王」。
> 最后增援的空投炸弹全屏清场，慢镜头收尾。劫持者冷笑：“老K 会来接我的。”——实验罐头正是老K“罐头雨”计划的伏笔。
>
> 前面的战斗会掉落**神装武器**（群攻）：喵喵散弹（扇形 8 连发）、罐头激光（贯穿一排）、肉垫火箭（范围爆炸）。神装带“友军识别”，不伤人质。

### 第一章 · 雾港码头
> 线索指向港口的 7 号仓库。

- 夜影登场，在集装箱顶部提供狙击支援（玩家可切换角色）。
- 关卡特色：集装箱迷宫、可吊起的货箱（射断绳子砸敌人）、雾气降低视野。
- 发现浣熊们在走私大量 **工业级开罐器**——为什么需要这么多？
- 章末小 Boss：**獾·铁锤**，扛着火箭筒在码头吊车上开火。

### 第二章 · 宠物医院人质事件
> 黑眼圈帮占领了城中心的宠物医院，挟持了 12 名病患。

- 大福登场。关卡核心是 **潜入 + 救人质**：人质被击中会失败，需要用盾牌掩护、精准射击。
- 多个房间连续破门，考验节奏。
- 救出的人质里有一位老会计——海狸 **算盘先生**，他透露：“他们逼我画出金罐储备库的地下管道图……”
- 剧情反转：原来医院只是佯攻，用来吸引警力。

### 第三章 · 地铁追击
> 匪帮劫持了一列地铁，准备从地下运走开罐设备。

- 铃铛登场，从警局指挥中心黑进地铁控制系统，后在车厢顶与队伍会合。
- 关卡特色：**横向卷动的列车**，车厢间跳跃、隧道灯光明暗交替、对面来车需要趴下躲避。
- 夺回控制室，但设备已在中途下车运走。
- 关键线索：铃铛破解匪徒手机，看到一句话——“老K 说：明晚，罐头雨。”

### 终章 · 金罐储备库
> 黑眼圈帮全员出动，从地下管道攻入储备库。

- 四人小队全员上阵，玩家可随时切换角色，AI 队友跟随。
- 多阶段大关：地下管道 → 金库大厅（防守波次）→ 屋顶决战。
- **Boss 战 · 垃圾桶之王老K**
  - 阶段一：机甲用垃圾桶盖当盾牌横扫，需要绕背打油箱。
  - 阶段二：召唤小毛贼 + 发射“罐头导弹”，地面落点圈。
  - 阶段三：机甲损毁，老K 亲自持双枪逃向直升机，限时追击。
- 结局：老K 被铐上直升机。他的真实目的揭晓——**他想用开罐器打开所有罐头，免费分给城里吃不饱的流浪动物**。
- 尾声：豆包沉默片刻，在报告里写下：“建议市政府成立流浪动物食堂。”

> **彩蛋片尾**：监狱里，老K 看着窗外新开的“爪爪食堂”，第一次露出了笑容。镜头一转——一只神秘的狐狸在暗处收起了照片……（续作钩子）

## 五、核心玩法

### 操作（PC）
| 按键 | 动作 |
|---|---|
| `WASD` | 移动 |
| 鼠标 | 瞄准（角色上半身跟随鼠标转向） |
| 左键 | 射击 |
| 右键 | 精准瞄准（移动变慢、准星收缩、视角向瞄准方向偏移） |
| `Space` | 翻滚（带无敌帧） |
| `R` | 换弹（支持“完美换弹”） |
| `Q` | 角色技能 |
| `E` | 互动：破门 / 上铐 / 解救人质 |
| `1-4` | 切换队员 |

移动端：双虚拟摇杆（左移动、右瞄准射击）+ 右侧技能/翻滚按钮。

### 关键系统
1. **掩体系统**：靠近矮墙/箱子自动蹲伏，减伤 70%；掩体可被打坏。
2. **破门系统**：门前按 E 踹门 → 进入 1.5 秒子弹时间 → 屏幕变暗、敌人高亮，是关卡节奏的高潮点。
3. **非致命设定**：敌人被击倒后头顶冒星星晕倒，按 E **上铐** 可获额外分数（保持可爱、全年龄向）。
4. **完美换弹**：换弹时弹出进度条，在亮区按 R 立刻完成并获得短暂伤害加成。
5. **评分系统**：每关按 时间 / 命中率 / 上铐数 / 人质无伤 给出 S·A·B·C 评级。

## 六、手感设计（操作感清单）

“好不好玩”一半在这里，原型阶段优先打磨：

- **命中反馈**：命中瞬间 hit-stop（30~60ms 冻帧）、敌人白闪、击退位移、数字跳出
- **开枪反馈**：枪口火光、弹壳抛出并落地停留、轻微镜头后坐（向射击反方向震动）
- **镜头**：平滑跟随 + 向瞄准方向前瞻偏移；爆炸时镜头震动 + 轻微缩放
- **翻滚**：残影拖尾 + 落地扬尘；翻滚可取消开枪后摇
- **准星**：动态扩散，移动时变大、停下/右键收缩；命中出现 ✕ 标记，击倒出现红色 ✕
- **受击**：屏幕边缘方向指示器 + 角色红闪 + 短暂镜头抖动；低血量时画面边缘发红、心跳音
- **音效**：每种枪独立音色；猫狗特警的语音短句（击倒“搞定！”、换弹“掩护我！”）

## 七、界面与交互设计

整体风格：**“警局档案 × 潮玩”**——扁平插画 + 粗描边，警用藏青为底，橙色强调。

### 配色
| 用途 | 颜色 |
|---|---|
| 主色 · 警用藏青 | `#1B2A4A` |
| 强调 · 警示橙 | `#FF7A1A` |
| 中性 · 奶油白 | `#FFF4E0` |
| 敌方 · 匪帮紫 | `#6B3FA0` |
| 危险 · 警报红 | `#E63946` |

### 关键界面
1. **主菜单 = 警局任务板**
   软木板上钉着案件照片和红线，鼠标悬停照片会轻微翘起；点击章节照片 → 镜头推进到该案件档案。

2. **角色选择 = 警员证**
   每个角色是一张可翻转的证件卡，正面立绘 + 姓名，翻面显示属性雷达图和技能演示 GIF。

3. **任务简报 = 局长投影**
   黑屏中投影仪“咔哒”亮起，局长老灰用激光笔在地图上标注目标，字幕打字机效果。

4. **战斗 HUD**（极简，不挡视野）
   - 左下：**狗牌形状** 的角色头像 + 血条，受伤时狗牌晃动
   - 右下：弹药以 **小罐头图标** 排列，打空一个变空罐；技能冷却是环形进度
   - 顶部居中：当前目标（如“解救人质 3/12”）
   - 屏幕边缘：敌人方向指示、受击方向指示
   - 小队头像（多人关卡时）：左侧竖排，按 1-4 切换时有卡片弹出动画

5. **暂停菜单**：画面模糊 + 侧边滑出“对讲机”样式菜单

6. **结算 = 毛绒日报头版**
   报纸旋转飞入镜头定格，头条标题根据评级变化：
   - S：“特警队完美出击！市民称赞猫狗英雄”
   - C：“特警队险胜，局长：下次少吃点零食”
   下方是数据小栏目 + 评级印章“啪”地盖上。

### 交互原则
- 所有按钮都有 **悬停 / 按下 / 释放** 三态动画与音效
- 页面切换使用统一的“百叶窗/警用胶带”转场
- 支持全键盘 & 手柄导航，焦点高亮清晰

## 八、美术方向

- **2.5D 实现**：3D 低多边形场景 + 正交相机 45° 俯视（等距视角），角色为 Q 版三头身
- 柔和的环境光 + 每关一个主题光色（便利店冷白、码头雾蓝、医院浅绿、地铁暖黄闪烁、金库金色）
- 描边 + 色块着色（Toon Shading），保证可读性：我方暖色描边，敌方紫色描边

## 九、技术方案

- **引擎**：Godot 4.5（GDScript），项目在 `game/` 目录
- **画面**：3D 场景 + 正交相机 45° 等距俯视；卡通着色 + 外描边；辉光、环境光遮蔽
- **素材**：首版全部用代码生成低多边形模型、矢量 UI 和程序化音效，后续可替换为美术资源
- **里程碑**
  1. ✅ **M1 可玩原型**：序章便利店——移动、射击、翻滚、掩体、破门子弹时间、上铐、人质、完整 UI 流程
  2. **M2 手感打磨**：根据试玩反馈调数值、加音效细节、手柄支持
  3. **M3 内容扩展**：4 名角色、5 种敌人、第一~二章
  4. **M4 完整版**：全部章节、Boss 战、过场动画
